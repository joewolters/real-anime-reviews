## The overhaul — your items

Kill-switch:** now a branded lamp pill (green ON / red OFF) on the reports page.
**5. Inline placement + dedupe.** The mechanism: the toolbar **📷 inserts the image at your cursor** as an `[img:N]` token (N = the image's slot, 1-4). The body text **never carries a path** — the token is just an index into the post's own rules-pinned imageRefs, so there's nothing to inject. Renderers swap tokens for figures in prose order; un-placed images trail as the gallery (old posts render unchanged). Removing a picked image renumbers your tokens. **Paste a screenshot straight into the composer** (or drag-drop) and it attaches + places itself. **Dedupe scope I chose: PER-USER, exact bytes** — you can never upload the same file twice (the spam case), but two different people sharing the same panel stays legal (an anime forum needs that). Enforced in the pipeline CF via a sha-256 registry with an **atomic claim** (race-proof) and a **self-heal** (deleting an image un-blocks re-uploading it); the picker pre-checks and refuses politely before any upload burns ("You've already posted this exact image"). Alternatives if you want them: per-thread (looser) or global (blocks legit reuse — I advise against).
**6. Reviews:** the review composer has the same 📷/picker — images inline in the body or trailing, same rules pin, same report/remove, swept on review delete. (Storage rules needed zero changes — review uploads ride the same locked path shape.)
**8. Thread thumbnail + comments:** the thread picker's **🖼 star picks your card thumbnail** (starred, else the first image — so an image thread always gets a card picture like OPM's; the anime cover still wins when both exist). **Comments AND comment-replies** get the full inline treatment too — picker, 📷, tokens, lightbox, ⚑.
**9. Cohesion:** verified by the review as **ONE system** — one figure builder, one slot resolver, one lightbox, one picker across all five composers, same ⚑ everywhere.
