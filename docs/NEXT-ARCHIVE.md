## ⭐ v1.8.4 — Discovery & Blend: gate-0 design study (PROPOSED, awaiting Blake's picks)

> **Why this is here:** the FULL design study was written to `docs/SHIP-OUTPUT.md`, which is a ROLLING doc (overwritten every Code response) — so the detail is banked here in NEXT.md (persistent) so no idea is lost if SHIP-OUTPUT turns over. **Status: proposed, nothing applied; awaiting Blake's answers to the 7 open Qs + a visual-direction pick.** Locked by Blake 2026-06-05: ONE big ship (no split); **characters KILLED** (the background concept replaces them as the sole visual identity); Quotes-admin page = trailing nice-to-have.

**The blend (the one idea everything serves):** a stranger must instantly get "this is one person's reviews" (Blake's 44 = the heart) vs "…and the wider world" (live AniList = a secondary neighbour, never a firehose). Three levers: (1) **heart-first place** — the Den is always the front door; For You / Discover are sideways steps (Direction-C in-page glides, header grows the entries); (2) **per-card legibility** — Blake's cards = gold rating + provenance; outside cards = a **NOT-REVIEWED sticker (no provider name)** + community score only; (3) **the room lightens as you leave the den** — the background layer is darkest in the Den, most open in Discover.

**Three surfaces:** Blake's Den (the 44, unchanged front door) · **For You** (rails from the user's saved-catalog genres/tags; signed-out → Trending) · **Discover** (live search pinning his 44 first + clickable Top-10 currently-airing + airing-by-genre + community top picks; fresh per log-on).

**Background concept (the sole visual identity — `body::after`, the freed v1.8.3 den-tint slot):** a black/line-work layer that **lifts per surface**, crossfading on glide (NOT scroll-linked = Gecko-safe; reduced-motion → instant). Three directions proposed:
- **Dir 1 "Lifting the veil" (my pick):** deep-purple-black + etched line-work/cracks (the welcome-door vocabulary, site-wide); opacity + line density step down Den ~0.92 → For You ~0.78 → Discover ~0.6 (city revealed as you go outward = the blend made literal). Cheapest + most on-brand.
- **Dir 2 "Constellation hush":** sparse star/constellation field thinning outward ("page in space"); slightly more paint.
- **Dir 3 "Aperture":** a vignette that opens per surface; simplest but least distinctive — fold its idea into Dir 1.
- Optional later (own gate, Gecko-profiled, droppable): a *very* subtle within-surface scroll-thinning via a throttled passive listener writing one CSS var.

**Data flow:** 3 NEW flat queries in `franchise-fetch.js` (additive, complexity-safe — flat lists, no nested relations): `SEARCH_QUERY` (search:$q, sort:SEARCH_MATCH), `TRENDING_QUERY` (sort:TRENDING_DESC), `AIRING_QUERY` (status:RELEASING + optional genre:$g). **Canary each against 101922 (Demon Slayer) first.** Clone the L2 cache pattern (`script.js:631-667`): `rar:trending:vX` 24h · `rar:airing:vX` 6–12h · `rar:search:` short/session. Home does NOT call AniList on first paint (Den is local); airing/trending fetch lazily the first time For You/Discover opens, then L2-served. Discover search reuses `/suggest`'s 350ms debounce + AbortController. For-You candidates = top genres/tags of the user's saved catalog entries.
